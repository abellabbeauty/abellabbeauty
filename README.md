# abellabbeauty website

This folder is ready to upload directly to GitHub Pages.

## Files
- `index.html` — the complete abellabbeauty website
- `.nojekyll` — tells GitHub Pages to serve the site as a normal static website

## Publish with GitHub Pages
1. Create a new GitHub repository named `abellabbeauty`.
2. Upload **both files** from this folder to the repository.
3. Open the repository's **Settings**.
4. Tap/click **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**.
7. Save.
8. GitHub will provide a public URL after deployment.

The website is self-contained, so there are no separate image, CSS, or JavaScript files to upload.

## Important
This is currently a booking prototype. Before using it for real client bookings, the live site still needs:
- a database to prevent double-bookings,
- secure card / Apple Pay payment processing,
- confirmation emails,
- nail-inspo file storage,
- secure cancellation/reschedule links.
